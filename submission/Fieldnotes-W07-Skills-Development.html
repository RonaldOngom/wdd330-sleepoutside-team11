Project overview

Fieldnotes is a responsive trip-planning experience for people preparing to spend time outdoors. A visitor can search for a place, review current conditions and a seven-day forecast, check air quality and daylight details, save places for later, and personalize temperature units and theme. The interface is populated from live Open-Meteo JSON responses.

The application is published as a separate route in the course repository. The SleepOutside storefront remains at the repository root; Fieldnotes is served from /fieldnotes/.

Rubric area Fieldnotes implementation and evidence Target
JavaScript app.js manages app state, validates search input, handles asynchronous place and weather requests, prevents stale responses from replacing newer results, converts units, and dynamically creates the forecast, condition, search-result, and saved-place interfaces from returned data. Third-party APIs api.js uses three Open-Meteo endpoints: Geocoding (geocoding-api.open-meteo.com/v1/search), weather Forecast (api.open-meteo.com/v1/forecast), and Air Quality (air-quality-api.open-meteo.com/v1/air-quality). Forecast and air-quality requests run concurrently; air quality is optional if that endpoint is unavailable. 25 / 25
JSON Geocoding returns an array of matching place objects. Forecast responses provide current conditions and parallel daily arrays, including date, weather code, maximum/minimum temperature, precipitation probability, sunrise, sunset, UV index, and maximum wind speed. JavaScript maps daily entries into seven visible forecast cards and uses the response to create conditions cards. 10 / 10
Advanced CSS styles.css provides responsive layouts, light/dark theme tokens, interactive hover/focus treatments and transitions, animated loading and entrance states, and reduced-motion support. These effects appear across controls, cards, loading, and content reveal states. 10 / 10
